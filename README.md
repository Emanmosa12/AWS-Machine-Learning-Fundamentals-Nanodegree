# Machine Learning Fundamentals Nanodegree

A collection of machine learning and deep learning projects completed as part of the **Machine Learning Fundamentals Nanodegree by Udacity, sponsored by AWS**.

This repository brings together four projects covering automated machine learning, deep learning, computer vision, transfer learning, and end-to-end machine learning workflows on AWS.

---

## 🎓 About the Program

The Machine Learning Fundamentals Nanodegree provided hands-on experience developing and deploying machine learning solutions using Python, PyTorch, AutoGluon, and AWS services.

The projects progressed from building individual machine learning models to designing complete, cloud-based ML workflows.

### Main areas covered

- Machine Learning
- Deep Learning
- Computer Vision
- Automated Machine Learning
- Feature Engineering
- Model Training & Evaluation
- Transfer Learning
- Hyperparameter Optimization
- AWS Machine Learning Workflows
- Model Deployment
- Serverless ML Applications

# 🚀 Projects

## 01 — Predict Bike Sharing Demand with AutoGluon

A regression project using **AutoGluon** to predict bike-sharing demand.

### Key concepts

- Exploratory Data Analysis
- Feature Engineering
- Automated Machine Learning
- Regression
- LightGBM
- Neural Networks
- Hyperparameter Optimization
- Kaggle Evaluation

### Result

The project improved the Kaggle RMSE from:

**1.80870 → 0.46291**

through feature engineering, model experimentation, and hyperparameter tuning.

📂 [View Project 1](./01-predict-bike-sharing-demand-with-autogluon/)

- PyTorch

- Image Prediction

### Project components

## 04 — Build a ML Workflow for Scones Unlimited on Amazon SageMaker

An end-to-end machine learning workflow using **Amazon SageMaker**, **AWS Lambda**, and **AWS Step Functions**.

The project builds an image classification workflow capable of distinguishing between bicycles and motorcycles and integrates the model into an event-driven application.

### Key concepts

- Amazon SageMaker
- Model Training & Deployment
- AWS Lambda
- AWS Step Functions
- Amazon S3
- Image Classification
- Model Inference
- Confidence Thresholds
- Event-Driven ML Workflows
